# Student Agency storyboard

A static website with 14 timestamped storyboard segments and a proposed rerecording script. No build or installation is needed.

## Publish with GitHub Pages

1. Create a GitHub repository, or open the repository you want to use.
2. Upload the contents of this folder to the repository root: `index.html`, `styles.css`, `review.js`, the entire `images` folder, `.nojekyll`, and this README. Keep the images folder structure intact. Do not upload the ZIP itself or nest the site inside an extra folder.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select your branch (usually `main`) and `/ (root)`, then Save.
6. Once GitHub finishes publishing, the Pages settings will show the website link.

For a project repository, the address is normally `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

## Edit

Edit `index.html` to change the text or styling. Images are in `images/`. All image paths are relative, so the page works under a GitHub Pages repository URL.

Current-screen descriptions are based on sampled video frames. Proposed narration is replacement wording, not an audio transcript.

## JMS review tools

Select text within one paragraph and use that segment's Highlight selected text button. Remove highlights with the corresponding Remove highlight button. Each segment has a review status and comment box.

Feedback saves locally in the reviewer's browser. It is not automatically sent to Rich or shared among visitors. Use Download feedback to create a Markdown file to send back. Save editable review creates a JSON backup; Open saved review restores that file after confirmation. Print / save PDF includes highlights, statuses, and comments.

Upload `styles.css` and `review.js` along with `index.html` and the images when updating GitHub Pages.

## Styling and assignment context

All CSS is in `styles.css`. `index.html` links to it near the top. The expandable original-assignment reference summarizes the supplied path instructions and outcome alignment. The storyboard wording now reflects the original assignments. Saved comments and statuses are retained; highlights are restored when the selected wording still matches.
